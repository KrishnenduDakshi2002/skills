# Triage labels

Map canonical workflow roles to existing tracker labels:

| Workflow role | Default label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation required |
| `needs-info` | `needs-info` | Waiting for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and agent-ready |
| `ready-for-human` | `ready-for-human` | Human implementation required |
| `wontfix` | `wontfix` | Will not be actioned |

Keep the left column stable. Change the configured tracker label when the repository already uses different vocabulary.
